## Issues Found and Fixed During Testing

1. `tests/tools.test.ts` had a flaky no-match grep case that scanned `src` and could timeout. The test now uses `package.json`, preserving the no-match behavior with much less IO.
2. Runtime snapshot files matched the old `*.json` session-meta filter, so `*.runtime.json` could be listed as a malformed session. Session listing now excludes `*.runtime.json`, and meta parsing ignores JSON files without `id` and `projectPath`. A regression assertion was added to `tests/session-storage.test.ts`.
