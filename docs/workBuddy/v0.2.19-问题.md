- 现象：`node_modules/better-sqlite3/build/Release/better_sqlite3.node` 按 `NODE_MODULE_VERSION 137`（Node 24）编译；测试运行在 Node 22（ABI 127）上，Jest 的模块加载器解析到该 `build/Release` 二进制 → `new Database()` 加载即抛 `Error: The module ... was compiled against a different Node.js version using NODE_MODULE_VERSION 137`。

- 影响套件（本轮实测 **13 failed / 9 passed**）：

  - `tests/storage-maintenance.test.ts`（cleanupStorage 等）
